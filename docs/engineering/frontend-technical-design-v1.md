# SmartWardrobe 前端技术设计 v1

## 目标

前端负责登录、衣橱列表、导入、详情四个核心页面，以及三预设身份切换后的稳定交互体验。

## 页面范围

- `/login`
- `/wardrobe`
- `/import`
- `/garment/[id]`

## 当前职责

- 提供三预设身份登录入口
- 在应用壳层展示当前身份和数据模式
- 保持导入、列表、详情、删除、搜索、筛选、排序交互稳定
- 让页面直接消费统一数据接口，不关心底层是本地预设模式还是 Supabase

## 运行时提示

- 登录页和应用壳都会显示当前数据模式
- 模式提示用于人工确认当前运行环境，不属于业务功能

## 设计原则

- 页面路径保持稳定
- 身份切换必须显式、清晰
- 空态、错误态、成功态需可解释
- 本地预设模式与 Supabase 模式下的页面语义保持一致
