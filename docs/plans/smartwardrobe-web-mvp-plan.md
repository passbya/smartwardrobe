# SmartWardrobe Web MVP 计划

## 当前落地版本

本计划最初用于定义网页端电子衣橱 MVP。当前实现已经超出最早的单一 demo 方案，现状应以以下口径为准：

- 登录采用三预设身份
- 数据按身份隔离
- 支持本地预设模式与 Supabase 双模式仓储
- 已具备搜索、筛选、排序、删除能力

## 仍然适用的核心范围

- 登录进入衣橱
- 服装导入和展示
- 自动分类
- 手动修正分类

## 已完成的扩展

- 三预设身份替换旧 demo 登录
- 浏览器烟测和 `full-check`
- Vercel 部署

## 现阶段维护原则

- 后续文档与实现以当前真实状态为准
- 不再沿用“单用户 demo 登录”描述
