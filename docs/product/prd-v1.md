# SmartWardrobe Web MVP PRD v1

## 文档信息

- 版本：v1.0
- 状态：冻结
- 更新日期：2026-04-19
- 适用范围：Web 端 MVP

## 产品目标

SmartWardrobe Web MVP 的目标是帮助用户把分散的服装信息集中到一个可浏览、可维护的电子衣橱中，并在录入后通过规则引擎完成基础自动分类，降低后续整理成本。

## 当前范围

### In Scope

- 三预设身份登录入口
- 单件服装录入
- 单张图片上传
- 服装列表展示
- 服装详情查看
- 规则自动分类
- 手动修改分类结果
- 搜索、筛选、排序
- 单件删除

### Out of Scope

- 真实注册登录
- 第三方登录
- AI 自动识图
- 推荐算法
- 批量导入
- 多用户协作后台

## 核心用户流程

### 流程 1：选择身份进入

1. 用户访问 `/login`
2. 用户在 `Luna`、`Nova`、`Iris` 中选择一个身份
3. 系统创建对应身份会话
4. 系统跳转到 `/wardrobe`

### 流程 2：导入服装

1. 用户从衣橱页进入 `/import`
2. 用户上传单张服装图片
3. 用户填写基础字段
4. 用户提交导入
5. 系统保存图片和服装记录
6. 系统执行规则分类
7. 系统跳转到详情页或列表页，并提示导入成功

### 流程 3：浏览与管理衣橱

1. 用户在 `/wardrobe` 查看当前身份的服装列表
2. 用户可按关键词、品类、季节、颜色筛选或排序
3. 用户点击任意服装进入详情页
4. 用户可删除单件服装

### 流程 4：修正分类

1. 用户在 `/garment/[id]` 查看自动分类结果
2. 用户手动修改分类字段
3. 用户保存修改
4. 系统持久化最终结果

## 页面说明

### `/login`

- 提供三个预设身份入口
- 展示当前数据模式
- 已有有效会话时直接跳转 `/wardrobe`

### `/wardrobe`

- 展示当前身份的服装列表
- 提供搜索、筛选、排序和删除入口

### `/import`

- 完成单件服装导入
- 导入成功后触发自动分类

### `/garment/[id]`

- 查看单件服装信息
- 手动修正分类结果
- 支持删除
