# SmartWardrobe 验收标准 v1

## 1. 文档信息
- 版本：v1.0
- 状态：冻结
- 更新日期：2026-04-18

## 2. 主流程验收
### AC-01 登录进入
- 用户打开 `/login` 后可看到品牌标题和进入按钮。
- 用户点击进入按钮后成功创建演示会话。
- 成功后自动跳转到 `/wardrobe`。

### AC-02 空衣橱展示
- 当用户尚未导入任何服装时，`/wardrobe` 显示空态提示。
- 空态中必须提供进入导入页的明确入口。

### AC-03 单件服装导入
- 用户在 `/import` 可上传一张图片并填写基础字段。
- `image`、`name`、`subcategory` 缺失时不能提交。
- 提交成功后图片和服装记录都被保存。

### AC-04 自动分类
- 导入成功后，系统根据 `subcategory` 自动补全 `category`。
- 若 `season` 为空且规则可补全，则系统自动写入默认季节。
- 用户已填写的字段不被规则覆盖。

### AC-05 服装展示
- 新导入服装可在 `/wardrobe` 列表中看到。
- 列表页展示的核心字段与详情页保持一致。

### AC-06 手动修正
- 用户可在 `/garment/[id]` 修改分类相关字段。
- 修改保存后刷新页面，结果仍然存在。
- 手动修改后分类来源应更新为人工修改。

### AC-07 基础筛选
- 用户可按 `category`、`season`、`color` 进行筛选。
- 筛选结果只展示符合条件的服装。

## 3. 异常态验收
### AC-08 登录失败
- 若创建演示会话失败，页面显示明确错误提示。

### AC-09 上传失败
- 若图片上传失败，页面显示明确错误提示。
- 用户已填写的表单内容不应丢失。

### AC-10 数据读取失败
- 若列表或详情页数据读取失败，页面显示错误态，而不是空白页。

### AC-11 不存在的服装记录
- 当访问不存在的服装详情时，页面显示“记录不存在”提示。

## 4. 交互与体验验收
- 页面文案为中文。
- 桌面端体验优先，移动端可正常使用。
- 用户从登录到完成首次导入的主流程应清晰直观。
- 所有成功、失败、空态都需要有明确反馈。
